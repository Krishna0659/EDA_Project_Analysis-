# Source and attribution

This portfolio project adapts the banking EDA notebook by **VenkyAdi**:

- Repository: https://github.com/VenkyAdi/EDA---Projects
- Selected directory: `Banking-Fraud-Analysis-Paisabazzar`
- Source commit: `7c247fe85517d0603572556afaecee72ab775db2`
- Retrieved: 1 November 2026

`Banking-Fraud-Analysis-Paisabazzar/Paisabazaar-EDA.ipynb` is the historical
reference. Its saved outputs and execution counts have been cleared to avoid
redistributing embedded customer records and stale results. The original code
and narrative are retained for attribution; this is not the runnable deliverable.
The original logo is retained alongside it. `references/upstream_README.md`
preserves the source repository overview.

The source notebook loads `dataset.csv`, but that file is absent from the source
repository. Its recorded description mentions 100,000 rows and 28 columns; those
figures have **not** been independently reproduced. No original observations have
been reconstructed from saved notebook outputs.

The source repository README mentions MIT, but there is no LICENSE file at the
pinned revision. No license grant for upstream material or the missing dataset
is inferred here. This adaptation preserves credit and does not claim original
authorship of the source notebook. Check upstream terms before redistribution.

New work in this repository includes a deterministic synthetic demonstration,
validated cleaning, reproducible EDA, customer-separated model evaluation,
aggregate charts, a completed notebook, tests, and project documentation.
The demonstration is newly generated and is not Paisabazaar customer data.
